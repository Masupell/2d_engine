Basic 2d Engine

Allows to draw different Textures and shaders on top, with optional uniforms.
THe ability to build custom meshes
Ui and World coordinates
Async texture loading and thread pool, handled by the engine.
Optional Frame Stats in debug mode
And basic Sound Playing using rodio
